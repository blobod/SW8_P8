Install Git LFS before pushing to repository:
https://git-lfs.com/

## How to install **Git LFS**

### For mac users:

  From their **website**: 
  https://git-lfs.com/

  Or using **Brew**:
  
    1. Open the terminal.
    2. Navigate to the directory of the repository.
    3. Run `brew install git-lfs`.
